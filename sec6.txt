## Procedure

**Step 1: Install WSL**
Open PowerShell as Administrator and run:

```powershell
wsl --install

```

**Step 2: Open the Ubuntu terminal**
Launch your newly installed Ubuntu distribution.

**Step 3: Install Nginx and OpenSSL**
Run the following commands to update your package list and install the required tools:

```bash
sudo apt update 
sudo apt install nginx openssl -y

```

**Step 4: Start Nginx**

```bash
sudo service nginx start

```

**Step 5: Create the certificate**
Go to your home folder and generate the self-signed certificate:

```bash
cd ~ 
openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -sha256 -days 365 -nodes -subj "/C=IN/ST=Maharashtra/L=Mumbai/O=TCET/OU=BCA/CN=localhost"

```

This creates two files: `key.pem` (your secret key) and `cert.pem` (your certificate). You'll see no visible output if it works. Check that the files were created and note your current path:

```bash
ls 
pwd

```

**Step 6: Edit the Nginx config**
Open the default configuration file:

```bash
sudo nano /etc/nginx/sites-available/default

```

Find the block that starts with `server {` and add these three lines inside it (replace `yourusername` with the output from your `pwd` command in Step 5):

```nginx
listen 443 ssl; 
ssl_certificate /home/yourusername/cert.pem; 
ssl_certificate_key /home/yourusername/key.pem;

```

Save the file by pressing `Ctrl+O`, `Enter`, and then exit with `Ctrl+X`.

**Step 7: Test and restart**
Verify that your Nginx configuration has no errors:

```bash
sudo nginx -t

```

It should report "syntax is ok" and "test is successful." If it throws an error, it will indicate which line is wrong. Once successful, restart Nginx to apply the changes:

```bash
sudo service nginx restart

```

**Step 8: View it in the browser**
Open your web browser and go to: `https://localhost`
WSL forwards localhost to Windows automatically, so this works without extra setup. A "Not Secure" warning will appear; click **Advanced** → **Proceed to localhost (unsafe)**. This warning is expected since it is a self-made certificate, not one issued by a trusted certificate authority.
